Repository
The project's folder online. Ours holds every page, the backend code, and the docs.
Publishing (a "commit")
Saving a new version of a file there, with a short note about what changed. GitHub keeps every earlier version, so nothing is ever lost and any change can be undone.
Live site
The public web page people actually use. The project copy and the live site are separate: this tool can update both in one go.
Token
A password-like key that lets this page act on your behalf. It's created once in Settings and saved in this browser only.
